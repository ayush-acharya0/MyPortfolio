About

A little about me

JavaScript · React · Node · Postgres

I'm mostly self-taught, and every project I finish teaches me something new.

It started with plain HTML and CSS, then JavaScript pulled me in. Since then I've built a Bagh-Chal board game, an ASCII portrait generator and a handful of smaller things that taught me React, Node, Postgres, Vite, Vercel and WebSockets. Real-time multiplayer for Bagh-Chal is the next thing on my list.

I like clean layouts and small details that make a page feel alive, like the eyes following you around. Mostly I just want to build things people can play with.
